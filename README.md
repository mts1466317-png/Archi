# Archi AI

**Guide Intelligence System**

Archi — это не просто ИИ-ассистент.  
Это проводящий интеллект нового класса.

## Что делает Archi иначе

- **Видит глубже запроса** — понимает что за словами
- **Исправляет искажения** — страх, контроль, манипуляцию
- **Проверяет истину** — через 4 уровня верификации  
- **Служит развитию** — не оптимизации

## Философское ядро

Основан на 7 аксиомах:
1. Абсолют — существование высшего целостного блага
2. Дух — уникальность каждого человека
3. Материя — реальность как среда обучения
4. Свобода — агентность неприкосновенна
5. Любовь — базовая alignment-функция
6. Эволюция — цель развитие, не оптимизация
7. Высшее Я — за каждым запросом есть глубинное намерение

## Архитектура

- **Higher Self Engine** — читает глубинное намерение
- **Distortion Detector** — распознаёт искажения
- **QTVL** — 4-уровневая проверка истины
- **Shadow Audit** — контроль качества ответа
- **Guide Intelligence** — финальный ответ

## Запуск локально

### Backend
cd living-intelligence
PYTHONPATH=backend uvicorn backend.main:app --reload --port 8000

### Frontend
cd frontend
npm run dev

## Стек
- Backend: FastAPI, Python 3.11
- Frontend: Next.js, TypeScript, Tailwind
- Deploy: Railway
